# @ai-rpg-इंजन/स्टार्टर-मर्चेंट

> **संरचना उदाहरण** — यह स्टार्टर दर्शाता है कि एक ऐसा गेम कैसे बनाया जाए जिसका मुख्य आधार युद्ध के बजाय दायित्व हो। यह सीखने का एक उदाहरण है, न कि नकल करने के लिए एक टेम्पलेट। अपना गेम बनाने के लिए [संरचना गाइड](../../docs/handbook/57-composition-guide.md) देखें।

**सॉल्ट रोड लेजर** — आप एक छोटे से व्यापारिक घर के कारक हैं। आपके पास जो सामान है, वह आपका नहीं है; आप उन पर बकाया हैं। आपके द्वारा प्राप्त प्रत्येक सिक्का किसी और के हाथ में एक चाकू है।

[एआई आरपीजी इंजन](https://github.com/mcp-tool-shop-org/ai-rpg-engine) स्टार्टर पैक कैटलॉग का हिस्सा।

## विषय

व्यापारिक दबाव, पहले मजाकिया और फिर विनाशकारी। सॉल्ट रोड पर कुछ भी दुर्लभ नहीं है - बाधा यह है कि आपने क्या वादा किया है। `liquidity` वह है जिसे आप बिना कोई ऋण लिए तैनात कर सकते हैं; `lien` तब जमा होता है जब आप ऐसा करने में असमर्थ होते हैं, और 70 पर एसेय गिल्ड एक सौंपी गई संपत्ति ले लेता है। 90 पर यह आपकी मुहर ले लेता है।

युद्ध मौजूद है और जानबूझकर एक **खराब सौदा** है। एचपी अधिकतम 24 है, जो कैटलॉग में सबसे कम सीमा है, और युद्ध संसाधन प्रोफ़ाइल में एक खाली `gains` सरणी है - कहीं भी कोई पंक्ति हिंसा को पुरस्कृत नहीं करती है। हमला करने से तरलता खर्च होती है, क्षति लेने से यह घटती है, और जीतने पर 5 और घटती है, क्योंकि आपने किसी की संपत्ति को नुक़सान पहुँचाया है।

## त्वरित शुरुआत

```typescript
import { createGame } from '@ai-rpg-engine/starter-merchant';

const engine = createGame(71);

// Register with the Assay Guild — the seal is what makes consignment possible
engine.submitAction('speak', { targetIds: ['assay-master-corvane'] });
engine.submitAction('choose', { parameters: { choiceId: 'register' } });

// Read the goods, contest the terms, then hand them over
engine.submitAction('appraise', { parameters: { itemId: 'bale-of-flax' } });
engine.submitAction('move', { targetIds: ['long-quay'] });
engine.submitAction('move', { targetIds: ['crooked-stair'] });
engine.submitAction('haggle', { targetIds: ['broker-inaya'] });
engine.submitAction('consign', { parameters: { itemId: 'bale-of-flax' }, targetIds: ['broker-inaya'] });

// Reconcile your own books
engine.submitAction('audit');
```

## प्रदर्शित पैटर्न

- **एक गैर-युद्ध प्राथमिक लूप** — पाँच वाणिज्य क्रियाएँ गेम को आगे बढ़ाती हैं; युद्ध स्टैक वायर्ड है लेकिन इसे दंड के रूप में मूल्य दिया गया है।
- **एक उलटा संसाधन प्रोफ़ाइल** — `CombatResourceProfile` जिसमें कोई `gains` नहीं है, इसलिए एआई कम-तरलता कारक को अलग करने की ओर धकेलता है।
- **एक पैक-स्थानीय मॉड्यूल** — `contract-core` स्टार्टर के अंदर रहता है न कि `@ai-rpg-engine/modules` में, क्योंकि इसमें ठीक एक उपभोक्ता है। दूसरे पर प्रचार करें।
- **नए निर्भरताओं के बजाय इंजेक्टेड ऑप्स** — स्थिति मशीनरी और मान्यता मूल्यांकनकर्ता को पारित किया जाता है, वही सीम `createEquipmentCore` उपयोग करता है।
- **ऐसे उपकरण जो आँकड़ों के बजाय यांत्रिकी को नियंत्रित करते हैं** — गिल्ड सील `consign` प्रदान करता है और लेजर बुक `audit` प्रदान करती है, इसलिए जब्ती एक क्रिया को हटा देती है।
- **एक अनियंत्रित जिला एक यांत्रिक के रूप में** — वॉरेन्स का कोई नियंत्रण करने वाला गुट नहीं है, जो इसे एकमात्र ऐसी जगह बनाता है जहाँ कोई एस्क्रो और कोई निवारण नहीं है।

## अद्वितीय यांत्रिकी

| क्रिया | यह क्या करता है |
|------|--------------|
| `appraise` | यह मांगी गई कीमत के मुकाबले वास्तविक मूल्य, दुर्लभता और उत्पत्ति को पढ़ता है। बेहतर `ledger` बैंड को संकुचित करता है। |
| `haggle` | एक कीमत पर विवाद करता है। तरलता की लागत आती है; जीती हुई मार्जिन उस प्रतिपक्ष के खिलाफ जमा की जाती है और आपके अगले `consign` द्वारा उनके साथ उपयोग की जाती है। |
| `consign` | भविष्य में भुगतान के मुकाबले सामान सौंपता है, जिससे नियत तिथि के साथ एक दायित्व बनता है। सामान तुरंत आपकी सूची से हट जाता है - वह अंतर संपूर्ण जोखिम है। |
| `underwrite` | एक शुल्क के लिए किसी अन्य पार्टी का जोखिम उठाता है। अब तरलता; यदि आपने जिस पार्टी की गारंटी दी थी, वह चूक करती है, तो दावा शुरू हो जाता है और ग्रहनधिकार लागू हो जाता है। |
| `audit` | आपकी पुस्तकों को समेटता है और विसंगतियों की रिपोर्ट करता है। लेजर बुक की आवश्यकता होती है - आप स्मृति से ऑडिट नहीं कर सकते हैं। |

**दायित्व घड़ी** एक टाइमर के बजाय गति पर चलती है। नियत तिथि वाली संपत्तियाँ `overdueTicks × value ÷ 10` पर ग्रहनधिकार जमा करती हैं। 70 पर ग्रहनधिकार पर जब्ती उस दायित्व को लेती है जिसका आइटम आईडी सबसे कम क्रम में होता है - नियतात्मक, कभी भी कोई रोल नहीं।

## सामग्री

- **4 जिलों में फैले 8 क्षेत्र:** सॉल्टगेट (वैधानिक बाजार), डॉकवर्ड (शुल्क और देरी), वॉरेन्स (बैरल पर नकद), और हाई काउंटिंग हाउस
- **4 एनपीसी** — एसे मास्टर कोर्वैन, हार्बरमास्टर डरेल, ब्रोकर इनया, कोषाध्यक्ष नल
- **3 शत्रु + 1 बॉस** — द स्टैंडिंग अकाउंट कोई प्राणी नहीं है बल्कि एक हिसाब है, जिसके चरण इस बात से जुड़े होते हैं कि आप कितने बोझ के साथ आते हैं।
- **3 खोज** — ओपन द बुक्स, द लेट कैरावान, द स्टैंडिंग अकाउंट
- **14 आइटम** को परिवर्तनीय व्यापारिक वस्तुओं और पाँच अद्वितीय उपकरणों में विभाजित किया गया है।

## आँकड़े और संसाधन

| आँकड़ा | भूमिका |
|------|------|
| `ledger` | अंकगणित, स्मृति, धोखाधड़ी का पता लगाना |
| `tongue` | बातचीत और भ्रम |
| `standing` | कौन आपकी गारंटी देता है |

| संसाधन | व्यवहार |
|----------|-----------|
| `hp` | 24 अधिकतम - कैटलॉग में सबसे कम |
| `stamina` | मानक क्रिया अर्थव्यवस्था |
| `coin` | आपके पास क्या है |
| `liquidity` | आप बिना कोई ऋण लिए क्या तैनात कर सकते हैं |
| `lien` | **उलटा** — खाली शुरू होता है और जब्ती की ओर बढ़ता है |

युद्ध `attack → tongue`, `precision → ledger`, `resolve → standing` को मैप करता है: एक कारक जो अंततः झूलता है, वह ऐसा धमकाकर और समर्थन करके करता है, कभी भी किसी को शारीरिक रूप से पछाड़कर नहीं।

## ऑन-लेजर प्ले (वैकल्पिक)

यह `@ai-rpg-engine/ledger-adapter` के लिए संदर्भ पैक है। इसमें इस पर कोई निर्भरता नहीं है - एक परीक्षण पुष्टि करता है कि यह कभी नहीं होगा - लेकिन इसकी यांत्रिकी वही हैं जिन्हें एडाप्टर को पूरा करने के लिए बनाया गया था: `consign` एक प्लॉट डिवाइस पहने हुए एक समझौता आदिम है, `audit` एक बजाने योग्य क्रिया के रूप में बाहरी सत्यापनकर्ता है, और ग्रहनधिकार जब्ती नामित बर्न क्षतिपूर्ति है जो कथा में आती है। [अध्याय 60](../../docs/handbook/60-xrpl-ledger-adapter.md) और [अध्याय 61](../../docs/handbook/61-xrpl-nft-gear.md) देखें।

## क्या उधार लेना है

दायित्व जीवनचक्र, यदि आपके गेम में ऋण है। इंजेक्टेड-ऑप्स पैटर्न, यदि आपके पैक को किसी प्रणाली की आवश्यकता है बिना कोई निर्भरता लिए। और `anti-inert.test.ts` में एंटी-इनर्ट ऑडिट - यह एक वास्तविक खेले गए सत्र के माध्यम से प्रत्येक प्रमुख यांत्रिकी का पता लगाता है और छह ऐसे पाए जो वायर्ड, स्कीमा-मान्य, यूनिट-ग्रीन और मृत थे।
