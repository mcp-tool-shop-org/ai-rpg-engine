# Scaffolding from this template

This directory is the in-repo copy of `@ai-rpg-engine/starter-template`.
Do not edit it as a game. Scaffold your own copy first (it names everything
for you):

```bash
npx --package=@ai-rpg-engine/cli ai-rpg-engine create-starter my-game --out=./my-game
```

`create-starter` copies `README.md` (the first-run surface, titled `# My Game`
until the chosen name replaces it) and rewrites placeholders. This file is
not in `package.json` `files` and is not copied into the new project.
